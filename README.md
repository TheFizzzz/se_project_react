# WTWR (What to Wear?)

## About the project

WTWR is a React front-end application that recommends clothing based on the current weather. Users can browse their wardrobe, view item details, and add new garments through modal forms.

## Live demo

[https://thefizzzz.github.io/se_project_react/](https://thefizzzz.github.io/se_project_react/)

## Functionality

- View hard-coded weather information and a clothing wardrobe
- Open item preview modals by clicking clothing cards
- Add new clothing items through a validated form modal
- Delete clothing items from the preview modal

## Technologies and techniques

- React 18 with functional components and hooks
- Vite for development and production builds
- CSS with BEM methodology
- Cabinet Grotesk font (self-hosted)
- ESLint and Prettier for code quality

## Running locally

```bash
npm install
npm run dev
```

The app runs at [http://localhost:3000](http://localhost:3000).

## Deployment

```bash
npm run deploy
```

Then set the GitHub Pages source branch to `gh-pages` in your repository settings.
